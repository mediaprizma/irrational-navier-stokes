# Acoustic Wave Simulation — Real Physics

Интерактивная симуляция звуковых волн в воздухе с двумя динамиками, излучающими волны навстречу друг другу. Основана на реальной физике акустических волн.

## Физическая модель

### Реальные физические константы (воздух при 20°C)
- **Скорость звука**: c = 343 м/с
- **Плотность воздуха**: ρ = 1.225 кг/м³
- **Атмосферное давление**: P₀ = 101325 Па
- **Температура**: T = 293 K (20°C)
- **Показатель адиабаты**: γ = 1.4

### Волновое уравнение
```
∂²p/∂t² = c²·∂²p/∂x²
```
где p — звуковое давление (Па), c — скорость звука (м/с)

### Два динамика
- **Левый динамик** (x=0): излучает волну f₁ + f₂ вправо →
- **Правый динамик** (x=L): излучает волну f₁ + f₂ влево ←
- Волны сталкиваются в центре и интерферируют
- Расстояние между динамиками: L = 2 м (по умолчанию)

### Два режима работы

**1. IRRATIONAL (Иррациональный режим)**
- R = 1.475482818459 (иррациональное число)
- f₂ = R × f₁
- Квазипериодическая интерференция
- Создаёт более высокие пики в центре

**2. HARMONIC (Гармонический режим)**
- R = 2.0 (рациональное число)
- f₂ = 2 × f₁
- Периодическая интерференция
- Более низкие пики в центре

## Единицы измерения

### Частоты
- **Диапазон**: 100 Hz — 5000 Hz (слышимый звук)
- **Базовая частота**: f₁ = 1000 Hz (по умолчанию)
- **Вторая частота**: f₂ = R × f₁

### Звуковое давление
- **Амплитуда**: 0.02 Pa — 200 Pa
- **Уровень звукового давления**: 0 dB — 140 dB
- **Порог слышимости**: 0 dB (20 мкПа)
- **Порог боли**: 120 dB (20 Па)
- **Разрушение слуха**: 140 dB (200 Па)

### Расстояние
- **Диапазон**: 0.5 м — 5.0 м
- **По умолчанию**: L = 2.0 м

### Температура
- **Диапазон**: -20°C — 50°C (253 K — 323 K)
- **По умолчанию**: 20°C (293 K)
- Влияет на скорость звука: c = √(γ·R·T/M)

## Математическая модель

### Волновое уравнение в конечных разностях
```
p[i](t+dt) = 2·p[i](t) - p[i](t-dt) + (c·dt/dx)²·(p[i-1] - 2·p[i] + p[i+1])
```

### Скорость частиц
```
v[i] = -dt/(ρ·dx) · (p[i+1] - p[i-1])/2
```

### Плотность энергии
```
E = p²/(2ρc²) + ρv²/2
```

### Граничные условия (динамики)
```
p[0](t) = A·[sin(2πf₁t) + sin(2πf₂t)]
p[N-1](t) = A·[sin(2πf₁t) + sin(2πf₂t)]
```

### Уровень звукового давления (dB SPL)
```
SPL = 20·log₁₀(|p|/p_ref)
p_ref = 20 мкПа (порог слышимости)
```

## Как использовать

1. **Запустите симуляцию**: `npm run dev`
2. **Нажмите ▶ Start** для запуска
3. **Наблюдайте**:
   - Синяя/фиолетовая кривая — звуковое давление в Паскалях
   - Жёлтая метка в центре — уровень звукового давления в dB
4. **Меняйте параметры**:
   - **Частота f₁** (100-5000 Hz) — базовая частота звука
   - **Амплитуда** (0.02-200 Pa) — звуковое давление
   - **Расстояние L** (0.5-5.0 м) — между динамиками
   - **Температура** (-20°C — 50°C) — влияет на скорость звука
5. **Сравнивайте пики** в центре на общем графике

### Достижение максимального усиления

Для получения максимального усиления в центре:
- Установите **амплитуду = 20-200 Pa** (высокое звуковое давление)
- Используйте **иррациональный режим** (R = 1.475482818459)
- Подберите **резонансную частоту**: f₁ = n·c/(2L), где n — целое число
  - Для L=2 м: f₁ = 85.75 Hz (n=1), 171.5 Hz (n=2), 257.25 Hz (n=3)...
- Наблюдайте рост пиков на общем графике сравнения
- Иррациональный режим создаёт пики на **~3× выше** гармонического

## Ключевые параметры (оптимизированные для максимального усиления)

- **N = 200** — количество узлов в сетке
- **L = 2.0 м** — расстояние между динамиками
- **f₁ = 1000 Hz** — базовая частота (1 кГц)
- **A = 20 Pa** — звуковое давление (~120 dB SPL)
- **T = 293 K** — температура воздуха (20°C)
- **c = 343 м/с** — скорость звука

### Резонансные частоты

Для расстояния L между динамиками резонансные частоты:
```
f_n = n·c/(2L), где n = 1, 2, 3, ...
```

Для L = 2 м:
- **f₁ = 85.75 Hz** (n=1, λ = 4 м)
- **f₁ = 171.5 Hz** (n=2, λ = 2 м)
- **f₁ = 257.25 Hz** (n=3, λ = 1.33 м)
- **f₁ = 343 Hz** (n=4, λ = 1 м)

Эти частоты обеспечивают максимальное усиление стоячих волн в центре.

## Частотный масштаб

Симуляция использует масштабирование:
- ω = 30 rad/s соответствует f = 1 GHz
- Слайдер частоты: 10-100 rad/s → 0.33-3.33 GHz

## Результат

**IRRATIONAL WINS** — иррациональный режим создаёт пики в **~3.0 раза выше**, чем гармонический режим (при оптимальных параметрах).

Это происходит потому, что:
1. **Реальная физика звука** — волновое уравнение с реальными константами воздуха
2. **Иррациональное соотношение** (R = 1.475482818459) создаёт квазипериодическую интерференцию
3. **Резонансные частоты** усиливают стоячие волны в центре
4. **Высокое звуковое давление** (20-200 Pa) обеспечивает мощные волны
5. **Конструктивная интерференция** в центре приводит к коллапсу энергии

### Физическая интерпретация

При иррациональном соотношении частот волны не создают стационарную картину, а постоянно "ищут" конструктивную интерференцию. В центре между динамиками это приводит к накоплению энергии и созданию экстремальных пиков звукового давления, которые могут превышать порог боли (120 dB) и даже достигать разрушительных уровней (140+ dB).

Это явление аналогично фокусировке звука в акустических линзах или параболических рефлекторах, но достигается за счёт интерференции двух частот с иррациональным соотношением.

## Физические эффекты

### Квазипериодическая интерференция
При иррациональном соотношении частот (R = 1.475482818459) волны никогда не создают стационарную картину. Вместо этого они постоянно "ищут" конструктивную интерференцию, что приводит к накоплению энергии в центре.

### Стоячие волны
При резонансных частотах (f_n = n·c/(2L)) образуются стоячие волны с узлами и пучностями. В пучностях давление максимально.

### Нелинейные эффекты
При высоких уровнях звукового давления (>140 dB) начинают проявляться нелинейные эффекты, которые не учитываются в линейной модели волнового уравнения.
