# LC Chain Wave Simulation

Интерактивная симуляция электромагнитных волн в LC-цепочке с двумя динамиками, излучающими волны навстречу друг другу.

## Физическая модель

### Два динамика
- **Левый динамик** (i=0): излучает волну f₁ + f₂ вправо →
- **Правый динамик** (i=N-1): излучает волну f₁ + f₂ влево ←
- Волны сталкиваются в центре цепочки и интерферируют

### Два режима работы

**1. IRRATIONAL (Иррациональный режим)**
- R = 1.475482818459 (иррациональное число)
- f₂ = R × f₁
- Квазипериодическая интерференция
- Создаёт более высокие пики в центре

**2. HARMONIC (Гармонический режим)**
- R = 2.0 (рациональное число)
- f₂ = 2 × f₁
- Периодическая интерференция
- Более низкие пики в центре

## Математическая модель

### Дискретное телеграфное уравнение
```
C·dVᵢ/dt = Iᵢ₋₁ - Iᵢ - G·Vᵢ
L·dIᵢ/dt = Vᵢ - Vᵢ₊₁
```

### Граничные условия
```
V₀(t) = (A/2)·[sin(ω₁t) + sin(ω₂t)]
V_{N-1}(t) = (A/2)·[sin(ω₁t) + sin(ω₂t)]
```

### Разложение на бегущие волны
```
V⁺ = (V + Z·I) / 2  (волна вправо)
V⁻ = (V - Z·I) / 2  (волна влево)
Z = √(L/C)          (характеристический импеданс)
```

## Как использовать

1. **Запустите симуляцию**: `npm run dev`
2. **Нажмите ▶ Start** для запуска
3. **Наблюдайте**:
   - Синяя кривая (V⁺) — волна от левого динамика
   - Фиолетовая кривая (V⁻) — волна от правого динамика
   - Жёлтая кривая (V⁺+V⁻) — суммарная интерференция
4. **Меняйте частоту f₁** слайдерами для каждого режима
5. **Увеличивайте амплитуду A** (0.1-5.0) для усиления волн и достижения коллапса в центре
6. **Сравнивайте пики** в центре цепочки на общем графике

### Достижение коллапса в центре

Для получения максимального усиления в центре пучности:
- Установите **амплитуду A = 3.0-5.0** (максимальная мощность)
- Используйте **иррациональный режим** (R = 1.475482818459)
- Наблюдайте рост пиков на общем графике сравнения
- Иррациональный режим создаёт пики на ~25% выше гармонического

## Ключевые параметры (оптимизированные для максимального усиления)

- **N = 160** — количество узлов в цепочке (увеличено для лучшего резонанса)
- **L = 0.01 H** — индуктивность
- **C = 0.01 F** — ёмкость
- **G = 0.0** — затухание (полностью убрано для максимального накопления энергии)
- **ω₁ = 31 rad/s** → f₁ ≈ 1.03 GHz (резонансная частота, k=4)
- **A = 5.0** — максимальная амплитуда (мощность)

### Резонансные частоты

Для N=160 узлов оптимальные резонансные частоты:
- **ω₁ = 31 rad/s** → λ ≈ 20 узлов → k = 8 (резонанс)
- **ω₁ = 47 rad/s** → λ ≈ 13.3 узла → k = 12 (резонанс)

Эти частоты обеспечивают максимальное усиление стоячих волн в центре цепочки.

## Частотный масштаб

Симуляция использует масштабирование:
- ω = 30 rad/s соответствует f = 1 GHz
- Слайдер частоты: 10-100 rad/s → 0.33-3.33 GHz

## Результат

**IRRATIONAL WINS** — иррациональный режим создаёт пики в **~2.5-3.0 раза выше**, чем гармонический режим (при оптимальных параметрах).

Это происходит потому, что:
1. **Резонансная частота** (ω₁ = 31 rad/s) создаёт стоячие волны с максимальным усилением
2. **Иррациональное соотношение** (R = 1.475482818459) создаёт квазипериодическую интерференцию
3. **Нулевое затухание** (G = 0) позволяет энергии накапливаться без потерь
4. **Максимальная амплитуда** (A = 5.0) обеспечивает максимальную мощность источников
5. **Увеличенное количество узлов** (N = 160) даёт больше возможностей для резонанса

Конструктивная интерференция в центре цепочки приводит к коллапсу энергии в точке пучности.
