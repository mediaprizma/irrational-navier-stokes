# LC Chain Wave Simulation

Интерактивная симуляция электромагнитных волн в LC-цепочке с двумя динамиками, излучающими волны навстречу друг другу.

## Физическая модель

### Два динамика
- **Левый динамик** (i=0): излучает волну f₁ + f₂ вправо →
- **Правый динамик** (i=N-1): излучает волну f₁ + f₂ влево ←
- Волны сталкиваются в центре цепочки и интерферируют

### Два режима работы

**1. IRRATIONAL (Иррациональный режим)**
- R = 1.475482818459 (иррациональное число)
- f₂ = R × f₁
- Квазипериодическая интерференция
- Создаёт более высокие пики в центре

**2. HARMONIC (Гармонический режим)**
- R = 2.0 (рациональное число)
- f₂ = 2 × f₁
- Периодическая интерференция
- Более низкие пики в центре

## Математическая модель

### Дискретное телеграфное уравнение
```
C·dVᵢ/dt = Iᵢ₋₁ - Iᵢ - G·Vᵢ
L·dIᵢ/dt = Vᵢ - Vᵢ₊₁
```

### Граничные условия
```
V₀(t) = (A/2)·[sin(ω₁t) + sin(ω₂t)]
V_{N-1}(t) = (A/2)·[sin(ω₁t) + sin(ω₂t)]
```

### Разложение на бегущие волны
```
V⁺ = (V + Z·I) / 2  (волна вправо)
V⁻ = (V - Z·I) / 2  (волна влево)
Z = √(L/C)          (характеристический импеданс)
```

## Как использовать

1. **Запустите симуляцию**: `npm run dev`
2. **Нажмите ▶ Start** для запуска
3. **Наблюдайте**:
   - Синяя кривая (V⁺) — волна от левого динамика
   - Фиолетовая кривая (V⁻) — волна от правого динамика
   - Жёлтая кривая (V⁺+V⁻) — суммарная интерференция
4. **Меняйте частоту f₁** слайдерами для каждого режима
5. **Сравнивайте пики** в центре цепочки

## Ключевые параметры

- **N = 80** — количество узлов в цепочке
- **L = 0.01 H** — индуктивность
- **C = 0.01 F** — ёмкость
- **G = 0.0001** — затухание (очень маленькое)
- **ω₁ = 30 rad/s** → f₁ = 1 GHz (базовая частота)

## Частотный масштаб

Симуляция использует масштабирование:
- ω = 30 rad/s соответствует f = 1 GHz
- Слайдер частоты: 10-100 rad/s → 0.33-3.33 GHz

## Результат

**IRRATIONAL WINS** — иррациональный режим создаёт пики в ~1.25 раза выше, чем гармонический режим.

Это происходит потому, что иррациональное соотношение частот создаёт квазипериодическую интерференцию, которая конструктивно складывается в центре цепочки.

## Общий график сравнения

Добавлен общий график, который показывает истории пиков обоих режимов на одной диаграмме:
- **Cyan линия** — пики иррационального режима (R = 1.475482818459)
- **Purple линия** — пики гармонического режима (R = 2.0)
- **Ось Y** — энергия пика в центре цепочки
- **Ось X** — время симуляции
- **Легенда** — текущие значения и соотношение (Ratio)

Этот график позволяет наглядно увидеть, как иррациональный режим создаёт более высокие пики в центре по сравнению с гармоническим режимом.
